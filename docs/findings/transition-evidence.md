## Question
> What did brands that moved into AI-assistant surfaces change — org, content ops, stack, budget — per case, as the source states it?

## Answer
Of 108 cases, 99 name a change: content ops 63, stack 58, other 19, org 12, paid media 2 (counts measured-by-us from the rows below). Stack rests almost wholly on vendor pages at tier 5–6; org rests only on postings and filings at tier 2–3. No metric is claimed: this file counts named changes, not visibility, traffic or sales.
