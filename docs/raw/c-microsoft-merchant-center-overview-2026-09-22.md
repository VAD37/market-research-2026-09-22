# What is Microsoft Merchant Center? - Microsoft Advertising API | Microsoft Learn

Note

Learn more about where Microsoft Shopping campaigns are available.

Tip

New to Microsoft Shopping campaigns? Learn how to get started in this training course.

Microsoft Merchant Center allows you to create a catalog feed, which includes images and other information about your products, so that your products can display on the Microsoft Advertising Network.

Product ads allow you to include product details such as image and price within your ads, delivering key information about the product offers that will help users make informed decisions before clicking on your ads (which often improves conversions). Product ads pull inventory from the Microsoft Merchant Center catalog feed files that you submit.
