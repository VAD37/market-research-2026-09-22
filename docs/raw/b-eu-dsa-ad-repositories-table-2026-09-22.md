A central-database absence is therefore never read below as an engine-level absence — the "page checked" column names the actual page checked for each engine.

## Corroborating academic measurement

`b-eu-popets-2026-ad-transparency-2026-09-22.md` (PoPETs 2026, Benzaamia/El Fraihi/Abdelaziz/Goga) independently measured Article 39 ad-repository quality across Facebook, Instagram, YouTube and X (48,511 user-facing ad-explanation notices, systematic repository analysis) and found "transparency remains fragmented and inconsistent across platforms," with repositories providing "incomplete, misattributed, and at times difficult-to-interpret targeting data." This corroborates, via an independent peer-reviewed measurement, the Commission's specific finding against X. **None of the four platforms studied is an AI-assistant engine in this task's scope** — the paper is evidence about ad-repository quality generally, not about any priority-1/2 engine's repository specifically.

## Caveats

- Every "page checked" cell above names the actual URL read in this pull, per task instruction that a central-database absence is never read as an engine-level absence.
- Designation-list "average monthly active users" figures are each the provider's own self-reported number as of the cycle stated on the Commission's list (25.04.2023 for most; 31.08.2026 for ChatGPT/Reddit/Roblox), "without prejudice to the assessment by the Commission of the methodology used to calculate" them (Commission's own footnote, quoted in `b-eu-ec-designated-vlops-vloses-list-2026-09-22.md`). Where an engine's own page states a more recent figure (Bing: 155M for the period to 31.12.2025; ChatGPT: 159.1M for the period to 31.03.2026, matching the Commission list), both are recorded and not reconciled where they conflict.
- Three engines in this table (ChatGPT, Google, Bing) are the AI-assistant-adjacent services actually carrying VLOP/VLOSE status; four (Claude, Perplexity, Meta AI, Grok) carry no designation of their own — either because they are self-reported to sit below the 45-million-EU-user threshold (Claude, Perplexity) or because the designated entity is a different, non-assistant service of the same company (Facebook/Instagram for Meta AI; X for Grok). Amazon's designated service ("Amazon Store") is an e-commerce platform, not a named conversational-assistant surface, though its shopping-assistant features sit inside that designated service.
- No page reached in this entire cluster names any AI-assistant conversational surface (ChatGPT, Gemini, Copilot, Meta AI, Grok, Alexa/Rufus) inside its Article 39 ad-repository description. Every existing repository (Google, Microsoft, Amazon, Meta, X) is framed around the parent platform generally. This is recorded as a structural finding, not an inference: **the "ad unit inside a conversational AI answer" question reads `unknown — checked <page> 2026-09-22` for every engine with a live repository**, because no repository's own documentation distinguishes a conversational-AI ad unit from any other, and this cluster did not query any live repository interface for an actual entry (that would require operating each tool's search UI/API against specific advertisers — out of this cluster's scope and time).
- OpenAI's Article 39 obligation is prospective only (designated 31.08.2026, four-month compliance window). This is the one engine in the table where "repository not yet published" is a scheduling fact stated by the Commission itself (January 2027 compliance deadline), not an unexplained absence.
