## Verbatim

Earlier this week, OpenAI sent an email to advertisers about new ChatGPT Ads Manager product updates. These updates include testing a new multi-product carousel format for product feed campaigns, plus a number of updates to the ad manager itself.
Here is a screenshot of the Multi-product carousel format for product feed campaigns. OpenAI said it has started testing a carousel format for product feed ads that shows multiple products from an advertiser in a single unit. Here is what it looks like:
Here are the updates to ChatGPT Ads Manager announced this week:
- Conversion optimization for product feed campaigns beta: Conversion-optimized cost-per-click campaigns (oCPC) are now available in beta for product feed campaigns. This initial release supports click-billed campaigns using fixed or manual bidding with a positive conversion bid cap.
- New ways to create conversion-optimized (oCPC) campaigns: You can now clone an existing CPC campaign into a new oCPC campaign or create oCPC campaigns in bulk. During cloning, Ads Manager will prefill the conversion event when one eligible event is available; otherwise, you’ll be prompted to select one.
- Dynamic URL parameters: Use supported macros such as {campaign_id}, {ad_group_id}, {ad_id}, and {ad_account_id} in landing page query parameters, with values populated automatically at delivery time.
- Triple Whale integration: Connect ChatGPT Ads in Triple Whale to measure performance alongside other channels. Sonar Optimize is also now available for ChatGPT Ads, helping brands send stronger conversion signals back to OpenAI.
- Hightouch conversion API support: Hightouch now supports sending conversion events to ChatGPT Ads for measurement and optimization.
- Pixel validation diagnostics: View additional Pixel validation details in Ads Manager, including why events were dropped before being sent, the affected field, the error type, and a recommended fix. To access these diagnostics, go to Tools, then Conversions, and view the diagnostics panel on the right side.
- Automatic advanced matching (AAM) update: AAM is now the default for new Web pixels, and on August 17, 2026, OpenAI will also enable it for existing Web pixels. AAM helps match more conversions to ads using hashed customer information from website forms. If you prefer not to have AAM enabled, you can opt out before August 17 by going to Tools, Conversions, Data Source, then Edit pixel.
- ChatGPT Ads are coming soon to Brazil and Mexico: In the coming week, OpenAI will launch ChatGPT Ads in Brazil and Mexico, giving advertisers with business in these markets a new opportunity to expand their reach.
