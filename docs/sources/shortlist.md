## Pass 3 — vendor census

The roster is **discovered, not remembered.** No vendor enters from model memory. P3-c0 builds the roster; the vendor clusters then split it eight at a time.

**Roster rule — rewritten 2026-09-22 per B13.** The prior limb (b) admitted a single self-submitted tier-5 profile, so one PR cycle rostered a vendor; and the rule screened out quiet vendors it was never written to exclude. Three limbs now:

- **(a)** it appears on **two or more independent non-listicle sources** — a filing, a funding announcement, a review-site category page, a conference speaker list, a job posting, a practitioner thread, an engine's own partner page — where two pages by the same publisher, or two pages linking the same single origin, count once. Four publishers carrying one announcement are one source.
- **(b)** it has a **filing** at tier 2 (`channels.md` C13, C67), **or** a funding record at tier 5 (C14–C16) corroborated by one source that is not the vendor, its investors, or a syndication of their announcement.
- **(c)** a name appearing only in listicles or in a single review corpus is recorded in a **held** list with the pages it appeared on, counted in the screened total, and rostered if any later pull produces an independent source. Held is not screened-out: a held name is re-checked at the end of P3-c0, not discarded.

A name reaching none of the three is recorded in the screened count and **not** rostered.
