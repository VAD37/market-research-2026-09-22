# Baseline — the user's BA brief template. Run R0 reads this instead of an external method.

Set by the user 2026-09-23. Verbatim below this line.

BA report template — new idea / new market / solution potential / risk brief

1. Headline — one sentence answer. Would director repeat it to their boss?
2. Why now — 3 bullets. What changed in world. Not what we did.
3. Market — size (range + method), growth, buyer, budget line it steals from. Confidence grade per number.
4. Solution space — what exists, gaps, where hypothetical product could sit. Not build plan.
5. Evidence ladder — proven / inferred / assumed. Explicit. Table.
6. Risks — kill-shots first. Likelihood, impact, early signal, mitigant (if any).
7. Unknowns — what missing, why (blocked/unfound/unknowable), cost to close.
8. Decision / ask — options with tradeoffs. Or explicit "no decision".
9. Appendix — glossary (every acronym), sources graded, method, raw tables.

Test per section: "so what?" — no answer, section dies.
Section titles are full-sentence takeaways: reading titles alone gives the whole story.
